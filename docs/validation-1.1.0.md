# SpeakerHop 1.1.0 リリース候補の検証

実施日: 2026-11-01。リリース名は `1.1.0`、アプリとMSIXのバージョンは `1.1.0.0`。
GitHub公開状況は [1.1.0リリース](https://github.com/mmiyaji/SpeakerHop/releases/tag/v1.1.0) を参照。Store提出と公開は別途管理する。配布MSIXは未署名。

## 今回の確認

- 単体テスト: 最終版180件成功、失敗・スキップなし。
- `tests/install-local.transaction.tests.ps1`: 更新と失敗時復旧のモックテスト成功。実際のインストールを変更する試験ではない。
- `build-package.ps1 -Version 1.1.0.0`: self-contained .NET / x64 Release publish成功、警告0・エラー0。未署名MSIXの生成成功。
- バージョンの指定元: `SpeakerHop.csproj`、`Package.appxmanifest`、`build-package.ps1` を `1.1.0.0` に統一。

## 直前の実機確認と今回の範囲

直前の1.0.35.0で言語確認のキャンセル、確定、保存失敗時の復元と再試行を確認した。
1.0.36.0では通常版の連続起動と別パッケージのテスト起動について、動作中のプロセスが1つに保たれ、既存の設定画面が表示され、ショートカット登録エラーが出ないことを確認した。保存済み設定は変更されていない。

当初の候補はそのコードからバージョンとドキュメントを更新したもの。その後、下記のキー名・入力処理の修正を追加した。全言語・全画面の実機試験は繰り返していない。
当初の準備時にはアプリ全体の最終スモークとWACKは未実施だった。最終確認の結果は末尾に追記した。PC再起動、クリーン環境での導入、署名は未実施。
初回準備時は1.0.36.0を保持し、キー入力修正の確認時に1.1.0.0へローカル更新した。

## キー名・入力処理の追補

- Space、編集・移動・テンキー、IME、ブラウザー／メディアキーの名前を補完。数字・英字間の未定義コードを文字と誤認する範囲指定を修正。
- 記号キーはWindowsの現在の配列から名前を取得。日本語配列の `@`、`:`、`;` 等をネイティブAPI経由で確認した。未定義・解決できないキーだけはコード表示を残す。
- Ctrl＋Tab／Enter／Escape等を入力可能にし、修飾なしのTab／Enter／Escapeはダイアログ操作用に維持。
- 単体テスト180件成功。追補後のRelease publishは警告0・エラー0、MSIX生成成功。ログ: `artifacts/release-1.1.0-keynames-build.log`。
- `C:\Apps\SpeakerHop\1.1.0.0` にローカル更新。実際のキー入力欄でSpace、Ctrl＋Enter、Ctrl＋Tabの表示と、Escによるキャンセルを確認した。保存済み設定は更新前のファイルと一致。
- 開発用ZIP、MSIX、SHA-256は追補後の成果物へ更新した。全言語・全画面の再検証は行っていない。

## 公開直前の最終確認

- Release構成の単体テスト180件成功、インストーラー復旧モック成功。最新の起動・設定保存・ショートカット入力のコードレビューで公開を妨げる問題なし。
- インストール済み1.1.0.0で全5タブを確認し、利用規約を表示。言語変更確認ではキャンセルに初期フォーカスがあり、キャンセル後の保存済み設定は不変。
- 終了確認の初期フォーカスがキャンセルであることを確認。正常終了後の新規起動ではメイン画面を表示せず、もう一度起動すると同じプロセスで設定画面を表示した。
- 全5タブのスクリーンショットを確認。日本語・英語のStore用各4画面を1920×1032で更新した。英語への変更は確認操作を経て行い、日本語へ戻した後に保存済み設定の一致を確認した。全言語・全テーマの再試験は行っていない。
- 最初のWACKは全体PASS。ただし任意のApp Resources検査にPRIマップ名の不一致があったため、MSBuildに `ProjectPriIndexName=$PackageName` を渡すよう修正した。既存25リソースを維持し、マップ名が `mmiyaji.SpeakerHop` に一致することを確認。
- 修正版パッケージの実機起動・デバイス画面・バージョン表示と設定保持を確認。MSIXと実際の登録先でEXE・Core DLL・PRI・XBFのハッシュが一致した。
- WACK再検査: 全体PASS、24検査、必須の失敗0件。任意検査2件に指摘あり。App Resourcesは、MSIXと登録先のPRIが同一で、正しい `mmiyaji.SpeakerHop` マップを持つことを確認しても `0x80073B1F` を報告した。Blocked Executablesは同梱Microsoft .NETランタイム内の文字列参照（cmd、reg、MSBuild等）を指摘した。審査向けメモにも記載し、指摘なしの合格とは表現しない。
- 最終ビルドログ: `artifacts/release-1.1.0-final-build.log`（警告0・エラー0）。再検査レポート: `artifacts/SpeakerHop_1.1.0.0_wack-final.xml`。レポートにはローカル環境の情報が含まれるため配布ZIPには含めない。

Storeのアカウント設定と提出状況は [Store提出メモ](releases/store-1.1.0.md) を参照。GitHub公開をStoreの審査通過・公開と混同しない。
