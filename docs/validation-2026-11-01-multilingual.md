# 多言語UI検証（1.0.33.0）

2026-11-01、`codex/ui-consistency` にて実施。

## 修正

- 固定の日英併記ファイルを読む方式を、選択言語に対応した `Legal/<言語コード>/` の文書を読む方式へ変更。
- 日本語・英語・中国語（簡体字／繁体字）・韓国語・ドイツ語・フランス語・スペイン語の著作権、利用規約、プライバシーポリシー、第三者ライセンス案内を同梱。
- 第三者ライセンスの原文と出典一覧は変更せず、翻訳した案内とは別に選択可能。
- 残っていた英語の機器切替、未設定、機器選択、削除、登録失敗などのラベルを補完。
- ドイツ語で折り返されていた有効列の見出しを短縮。フランス語・スペイン語の機器選択ラベルを短縮。
- 長い修飾キーの組み合わせを折り返し表示し、著作権表示も選択言語へ追従。

## 検証範囲と結果

- 検証用の独立したアプリID・設定領域を使用。通常のアプリの設定や音声状態は検証操作で変更しない。
- 全8言語、1040×720／540×720、ダークテーマ、表示倍率100%で全5タブを確認。
- 80タブ画面、8文書ダイアログ、16の情報タブ下部画面を撮影（計104枚）。
- UI Automationによる可視操作部品の横方向の境界検査、ショートカット行・操作部品の個数検査が成功。
- 全32文書を実際に開き、本文が対応言語の同梱ファイルと一致することを確認（改行・空白のみ正規化）。
- 通常幅と狭い幅で情報タブ下部までスクロールし、終了ボタンを確認。
- 文字の切れ、ボタン同士の重なり、長いラベルの表示を目視確認。長い本文や一覧は縦スクロールで閲覧できる。
- WinAppが一部のPopupHostを合成して出力する撮影上の重複は、アプリのレイアウト崩れと区別して確認。
- 単体テスト116件成功。Releaseビルドは警告0・エラー0、MSIX生成成功。
