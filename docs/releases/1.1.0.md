# SpeakerHop 1.1.0 リリース準備

**状態:** リリース候補の準備中。公開済みではありません。

**リリースタイトル案:** SpeakerHop 1.1.0 — 動作安定性と使いやすさの向上

## リリースノート案

設定画面を整理し、出力デバイス、ショートカット、各種設定をコンパクトで見やすい配置にしました。現在の既定出力デバイスが一覧で分かるようになっています。

ショートカット編集と登録時の動作を改善しました。新規設定では他アプリとの競合が起きにくいキーの組み合わせを使い、既存ユーザーの保存済みショートカットは更新時に維持します。出力ミュートとマイクミュートは別の操作です。マイクミュートのショートカットは自動設定されません。

言語を変更する前に確認を表示し、設定画面に言語名を分かりやすく表示します。著作権表示、利用規約、プライバシーポリシー、第三者ライセンス案内を、日本語、英語、中国語（簡体字・繁体字）、韓国語、ドイツ語、フランス語、スペイン語に対応しました。

設定の保存、起動時の表示、パッケージ更新後の単一起動、インストーラーの更新失敗時の復元を改善しました。

導入方法は [開発用ZIPの導入](INSTALL.md)、確認結果は [検証記録](../validation-1.1.0.md) を参照。

## 配布物と動作要件

- **開発用 ZIP:** Windows Developer Mode を有効にし、Windows App Runtime 1.7 (x64) をインストールしてから展開し、同梱の `install-local.ps1` を実行してください。
- **unsigned MSIX:** x64 の署名前パッケージです。信頼済みの一般向けインストーラーではありません。Store 提出または署名用です。
- アプリは self-contained の .NET 8 アプリですが、Windows App Runtime 1.7 は別途必要です。
- 出力デバイスの既定設定には CoreAudio と一般に使われる PolicyConfig COM インターフェイスを利用します。Windows にこの操作の公開 WinRT API がないため、パッケージは `runFullTrust` を宣言します。

## 既知の制約

- グローバルショートカットが他のアプリで使用中の場合、登録に失敗することがあります。Windows エラー `1409` はこの競合を示します。設定画面で別のキーを割り当ててください。
- マイクミュートは Windows の既定キャプチャデバイス（Multimedia ロール）を対象にします。Communications ロールに別途設定されたデバイスは対象外です。
- unsigned MSIX はそのままでは信頼済みインストーラーとして利用できません。
