# SpeakerHop 開発用ZIPの導入

このZIPは開発者モード用です。署名済みの一般向けインストーラーではありません。
Windows x64、Windowsの開発者モード、Windows App Runtime 1.7 (x64) が必要です。
.NETランタイムは同梱しています。Windows App Runtimeとは別のものです。

## インストール・更新

ZIPをローカルフォルダーへ展開し、そのフォルダーでPowerShellを開いて実行します。

```powershell
.\install-local.ps1
```

ユーザープロファイル下への登録に失敗する場合は、書き込み可能な固定フォルダーを指定します。
リポジトリや一時フォルダーを指定せず、十分な空き容量を確保してください。

```powershell
.\install-local.ps1 -InstallDirectory C:\Apps\SpeakerHop\1.1.0.0
```

インストーラーは既存の設定を引き継ぎます。更新先を準備・検証してから動作中のアプリを終了し、登録失敗時は旧版の復元を試みます。
旧版と新版を手動で同時に起動しないでください。特に古いテスト版がある場合はトレイから終了してから更新してください。
インストール先のフォルダーは、登録が残っている間は移動・削除しないでください。

## 起動と設定

スタートメニューからSpeakerHopを起動します。初回は設定画面を表示し、その後は「起動時にメインウィンドウを表示」の設定に従います。
画面が表示されない場合は通知領域のトレイアイコンのメニューから設定を開けます。
再起動操作では既存のアプリが設定画面を表示します。

「デバイス」で循環対象を選び、トレイアイコンの左クリックまたはショートカットで切り替えます。
ショートカットの登録がエラー1409で失敗した場合、その組み合わせが別のアプリ等で使用中の可能性があります。「ショートカット」で変更してください。
更新時は保存済みのキー割り当てを維持します。マイクミュートは初期状態では未割り当てです。

言語は母語名と英語名を併記し、変更前に確認します。取り消した場合は変更されません。
設定の実際の保存先、著作権、利用規約、プライバシーポリシー、第三者ライセンスは「情報」で確認できます。

## 問題が起きた場合

設定の場所を「情報」で確認し、アプリを完全終了してから必要なファイルをバックアップしてください。
再インストール前に設定を削除する必要はありません。インストールや登録に失敗した場合はPowerShellのエラー内容を確認します。
サポート: [GitHub Issues](https://github.com/mmiyaji/SpeakerHop/issues)。ログにはパスやユーザー名が含まれる場合があるため、公開前に確認してください。
